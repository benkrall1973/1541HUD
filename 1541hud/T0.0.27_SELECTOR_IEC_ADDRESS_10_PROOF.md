# T0.0.27 — temporary IEC address 10 proof

This is the first intentional write test.

1. At device 8, it sends `M-W $0077`, length 2.
2. It writes `$2A` (LISTEN for device 10) to `$0077` and `$4A` (TALK for device 10) to `$0078`.
3. It closes device 8, waits briefly, then issues a read-only `M-R $E000` at device 10.
4. PASS is `PASS: ADDRESS 10 ROM BYTE = 133`.

The address change is only in live 1541 RAM. Reset or power-cycle returns to the normal address. No ROM image, OneROM slot, or flash data is modified.
