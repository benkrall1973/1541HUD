# T0.0.31 — UB3 shadow preflight

This is the smallest safe gate before the live UB3 shadow/reset experiment.

It verifies only:

- the candidate image is exactly 8 KiB;
- its five-byte CPU `$EB3A` virtual-jumper patch targets the requested address;
- UB3 currently reports both a JIFFYDOS slot and the Universal Bootloader;
- the current `inspect slots` result is recorded alongside the image SHA-256.

It deliberately does **not** upload anything, alter a OneROM slot, write UB3 RAM, flash firmware, or assert X2/reset.

The next test may use the verified OneROM v0.7.2 APIs to copy a known flash slot into a second RAM slot, patch that *RAM copy*, atomically select it, and pulse the already-wired UB3 X2 reset line low then release it to high impedance. That live test must preserve UB4 unchanged and must never drive X2 high.
