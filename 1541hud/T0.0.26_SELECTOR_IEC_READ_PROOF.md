# T0.0.26 Selector IEC read proof

One read-only command is sent to device 8:

`M-R $E000 length 1`

The program prints either the returned byte as decimal or `NO BYTE RETURNED`.

It changes no OneROM slot, ROM byte, drive RAM byte, or IEC address. It is built with the Selector project's BASIC V2 tokenization logic, not the earlier hand-built encoding.
