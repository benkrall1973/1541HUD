# T0.0.25 — Selector transport proof

## Purpose

Prove the existing, hardware-proven OneROM Selector IEC command/upload transport works with the current UB3 setup.

## Safety

This build is an exact copy of the supplied Selector PRG. It does not write drive RAM, execute new drive code, change the IEC address, alter a ROM image, or flash OneROM.

## Pass condition

Load and run the copied Selector PRG as normally. A pass is its normal search/communication flow reaching the ROM-selection menu and showing the expected configured slots.

## Meaning

A pass establishes that the C64-to-1541 command path to use for a later address-change experiment is sound. A later test must reuse that Selector transport implementation; it must not reuse T0.0.21–T0.0.24.
