# T0.0.33 — UB3 Turbo-Boot Preflight

## Purpose

Free UB3 `SEL_A` and `SEL_B` from physical ROM-image selection without altering the existing Universal bootloader or the stored ROM sets.

The generated configuration adds one OneROM setting:

```json
"turbo_boot": true
```

OneROM then ignores its physical image-select jumpers during its own boot and always serves the first non-plugin ROM set. In the existing UB3 configuration, that is the Universal bootloader pair. The Universal bootloader must then make its normal saved-ROM handoff to JiffyDOS, Original, or the selected ROM.

## Scope

- UB3 only.
- No UB4 changes.
- No changes to JiffyDOS, Original ROM images, or the Universal bootloader binary.
- No address-control wiring in this test.
- The source configuration's ROM sets and plugin references are preserved exactly.

## Safety

The build script is preflight-only by default. It writes a derived configuration beside the original and prints both SHA-256 hashes. UB3 is programmed only when `-Program` is explicitly supplied.

Keep the original source configuration. It is the rollback input.

## Run

Use the exact JSON configuration that was previously used to program UB3:

```bash
cd /c/1541HUD_LOCAL
git fetch origin
git switch --track origin/t0.0.33-ub3-turbo-boot-preflight

MSYS_NO_PATHCONV=1 powershell.exe -NoProfile -ExecutionPolicy Bypass \
  -File "$(cygpath -w 1541hud/Build-1541HUD-T033-Ub3TurboBootPreflight.ps1)" \
  -SourceConfig 'C:\path\to\your\actual\UB3-selector-config.json'
```

Review the generated `*.T0.0.33-turbo-boot.json` file. If its ROM-set count is correct and only `turbo_boot` was added, flash deliberately:

```bash
MSYS_NO_PATHCONV=1 powershell.exe -NoProfile -ExecutionPolicy Bypass \
  -File "$(cygpath -w 1541hud/Build-1541HUD-T033-Ub3TurboBootPreflight.ps1)" \
  -SourceConfig 'C:\path\to\your\actual\UB3-selector-config.json' \
  -Program
```

## Pass criteria

1. UB3 comes back on USB.
2. A physical SEL_A/B jumper no longer chooses a ROM image at UB3 boot.
3. The Universal bootloader still launches the ROM selected by the existing selector.
4. JiffyDOS can read a directory normally.
5. `onerom inspect gpio --all` continues to list SEL_A and SEL_B as 5 V and free.

## Rollback

Reprogram UB3 using the original source JSON without `turbo_boot`. No ROM image was changed by this experiment.
