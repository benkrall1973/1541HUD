# T0.0.30 — UB3 JiffyDOS address shadow

Creates a separate 8K JiffyDOS shadow image with a five-byte virtual-J1/J2 patch at CPU address `$EB3A`.

Safety:

- Validates the exact original address-initialization instruction sequence before writing any output.
- Never edits the source ROM.
- Does not upload, select, or reset OneROM/1541.
- Output is a candidate for a later RAM shadow-slot and reset test only.
