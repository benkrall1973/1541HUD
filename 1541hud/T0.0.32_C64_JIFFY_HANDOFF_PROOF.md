# T0.0.32 - C64 JiffyDOS handoff proof

The OneROM CLI live-image reader returned Universal Bootloader bytes at logical offset
`0x0B3A`. This test reads the same location through the 1541's own CPU memory map
after JiffyDOS has booted.

It sends seventeen IEC `M-R` commands to device 8 for CPU addresses
`$EB3A..$EB4A` and prints their decimal values.

Expected JiffyDOS sequence:

`173 0 24 41 96 10 42 42 42 9 72 133 120 73 96 133 119`

This is read-only. It neither modifies OneROM nor asserts reset. A match proves
that the JiffyDOS handoff image is CPU-visible and confirms that CLI `peek live`
is observing the bootloader layer rather than that image.
