# 1541HUD V0.0.32-RC1 Build Validation

## Status

V0.0.32-RC1 has been successfully built from the integrated release-candidate builder on the development branch.

This record documents build provenance only. It does **not** mark RC1 as hardware-proven. Hardware validation must still be completed on a real Commodore 1541 before promotion to V0.0.32.

## Build command

```powershell
powershell.exe -ExecutionPolicy Bypass -File ./1541hud/Build-1541HUD-Current.ps1
```

The wrapper invokes the V0.0.32-RC1 builder, which first reproduces the hardware-tested T0.0.15 source stack, creates separate RC1 source copies, changes only the release-candidate identity where required, rebuilds the USER and USB plugins, composes the Fire-24-E image, and preserves matching source files beside the generated firmware.

## Expected RC1 telemetry identity

The integrated USB source is expected to report the release-candidate identity consistently as:

```text
V0.0.32-RC1
```

This includes STATE, STATUS, HDRPHY, RPM, and SYNC records produced by the RC1 USB formatter.

## Hardware validation still required

Before RC1 can be promoted to the stable V0.0.32 release, verify on real hardware:

- normal drive boot and directory operation
- HOME anchoring and post-ROM-change HOME warning
- track and half-track movement
- motor ON/OFF
- head IN / OUT / STALL / PARK
- write-protect state
- density D0-D3
- physical-header RPM
- live sector display
- recent-sector FIFO
- raw PB7/SYNC/sec
- SYNC/revolution estimate
- seek-time RPM hold and fresh reacquisition
- post-seek SYNC report-boundary recovery
- original Commodore ROM game load
- JiffyDOS game load after HOME anchoring
- GUI reconnect / late connection behavior

Only the exact RC1 image identified by the SHA256 above should be used for this validation record.
